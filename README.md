# SkillRise - MERN Stack Learning Management System (LMS)

SkillRise is a full-stack Learning Management System built using the MERN stack. It provides a seamless platform for users to enroll in courses, manage their profiles, and access learning content. Admins can manage courses, users, and uploaded content through a dedicated dashboard.

## 🚀 Features

### 🌐 Frontend
- **React.js** for building responsive, component-based UI
- **Shadcn UI** for accessible and modern UI components
- **React Router DOM** for efficient client-side routing
- **Redux Toolkit (RTK Query)** for API handling and global state management

### 🔐 Authentication
- JWT-based authentication
- Secure password hashing with `bcryptjs`
- Protected routes for authorized access
- User registration, login, and profile management

### 🛠️ Backend
- Node.js and Express.js RESTful API
- MongoDB for database management
- Media uploads with **Multer** and **Cloudinary**
- Admin dashboard for course and user management

### ☁️ Deployment
- Deployed on **Render** with environment-specific configurations

### 🌟 Admin Features
- Create, update, delete courses

- Manage all users

- Monitor content and uploads

### 🧑‍🎓 User Features
- Register and login securely

- Browse available courses

- View and edit profile

- Access course materials and videos

### 📷 Media Uploads
- Course thumbnails and videos uploaded via Multer

- Stored and served using Cloudinary

### 🌍 Deployment
- The app is deployed on Render. Configure your build and start scripts appropriately and ensure that environment variables are set in Render’s dashboard.
